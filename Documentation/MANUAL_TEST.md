# Ручной тест Auraloom (перед релизом)

Цель — закрыть или подтвердить блокеры, которые нельзя проверить автоматически:
живой микрофон, слышимость в VB-CABLE, наушники, качество перевода на реальной речи,
сборка голосового профиля и стабильность.

Записывайте результат по каждому пункту: **PASS** / **FAIL** / **BLOCKED** и одну строку
«что именно произошло». Для FAIL приложите скриншот и время — по нему ищется строка
в логе.

**Где логи:**
- движок: `%LOCALAPPDATA%\Auraloom\workspace\logs\` (свежий файл `engine*.log`);
- история: `%LOCALAPPDATA%\Auraloom\workspace\history.jsonl`;
- настройки: `%LOCALAPPDATA%\Auraloom\workspace\ui_settings.json`.

**Перед началом:** закройте старые копии Auraloom (диспетчер задач → `Auraloom`,
`Auraloom`), запустите `dist\Auraloom.exe`, дождитесь внизу слева
«Движок: готов» (не «Загрузка моделей…»). Окно — 1280×840.

---

## 1. Запуск и окно

| # | Действие | Ожидание |
|---|---|---|
| 1.1 | Запустить EXE | Окно «Auraloom» открывается, интерфейс без чёрных/пустых областей |
| 1.2 | Уменьшить окно до 1280×840 | Ни одна кнопка не уезжает за край; на «Голосе» страница прокручивается колесом, справа видна полоса прокрутки |
| 1.3 | Пройти по всем разделам: Главная, Перевод, Голос, Модели, Настройки, История, Фразы | Каждый раздел открывается, ничего не обрезано снизу и справа |
| 1.4 | Закрыть и снова открыть окно | Настройки и активный профиль сохранились |

## 3. VB-CABLE: как слышат вас

| # | Действие | Ожидание |
|---|---|---|
| 3.1 | В игре/дискорде вход = `CABLE Output`; в Auraloom «Мост в кабель: включён» | Собеседник слышит переведённую речь |
| 3.2 | «Главная» → «В кабеле (ваш голос)» 100 % → сказать фразу | Собеседник слышит нормальную громкость, без клиппинга |
| 3.3 | Поставить 30 %, повторить | Стало заметно тише; 0 % — полная тишина |
| 3.4 | Поставить 150 %, повторить | Громче, но без хрипа; если хрипит — записать это как FAIL с значением |
| 3.5 | Выключить мост в кабеле | В кабель ничего не идёт |

## 5. Направление перевода (частый источник «бреда»)

| # | Действие | Ожидание |
|---|---|---|
| 5.1 | «Главная» → «Направление перевода» | Слева — язык собеседника, справа — «Русский» |
| 5.2 | «Перевод на:» = Испанский | Ваша русская речь переводится на испанский |
| 5.3 | Сказать по-русски при «Перевод на:» = Испанский | В истории строка `RU → <испанский>`; русский текст не искажён |

| 5.5 | Собеседник = Испанский, сказать по-русски с включённым входящим | Если в истории появляется `ES → …`, движок принял русскую речь за испанскую: это FAIL, зафиксируйте |

## 6. Прямой перевод RU → ES (качество и скорость)

Скажите по очереди, сверяя смысл (не дословность):

1. «Привет, меня зовут Карлос! Сегодня спокойный день, ничего особенного.»
2. «Что случилось, чувак? Всё в порядке?»
3. «Не шути, карнал, давай работать.»
4. «Ух ты, уже почти закончили.»
5. «Нет, не шути, всё нормально.»

| # | Проверка | Ожидание |
|---|---|---|
| 6.1 | Смысл перевода | Не потеряно второе предложение; нет выдуманных слов |
| 6.2 | Повторить фразу 1 дважды подряд | Второй раз — заметно быстрее (кэш переводов), текст тот же |
| 6.3 | Задержка от конца фразы до звука | Записать секунды (в «Статистике» ASR/MT/TTS). Рост больше чем на 50 % между повторами — FAIL |

## 7. Обратный перевод ES → RU

Собеседник = Испанский, входящий включён, говорите испанские фразы:

1. «¿Qué pasa, tío? Todo bien por aquí.»
2. «No bromees, carnal, vamos a trabajar.»
3. «Ya casi terminamos.»

| # | Проверка | Ожидание |
|---|---|---|
| 7.1 | Русский текст в истории | Смысл сохранён, без «Нет, нет, нет, нет» на осмысленную фразу |
| 7.2 | Смешанная речь (русский + испанский) | Русская фраза не превращается в испанскую тарабарщину |
| 7.3 | Тишина/шум | Нет озвучки выдуманных фраз |

## Как оформлять результат

Для каждого FAIL:

```
Пункт: 6.1
Что сделал: сказал «Привет, меня зовут Карлос! Сегодня спокойный день…»
Что ожидал: перевод обоих предложений
Что получил: Hola, me llamo Carlos.
Время: 10:42
Лог: engine-2026-11-18.log, последние 20 строк
```

Если пункт нельзя выполнить (нет оборудования, нет второго человека) — ставьте
**BLOCKED** и причину, а не PASS.

# PRODUCT_SPECIFICATION — Auraloom

Актуально на 2026-11-16. Источник истины — код и запуск; документ описывает
только то, что подтверждено.

## 1. Назначение

Локальное Windows-приложение для игрока RP-сервера RedZ (RedM/FiveM):

- быстрые озвученные реплики (звуковая панель) с доставкой в голосовой канал;
- живой перевод собственной речи RU → ES/EN/IT/OW в реальном времени;
- клонирование собственного голоса (XTTS-v2) и управление голосовыми профилями.

Работает офлайн: ASR, перевод и синтез — локальные модели.

## 2. Стек и способ запуска

| Что | Факт |
|---|---|

## 4. Пользовательские сценарии

### 4.1. Запуск движка (обязательный ручной шаг)

1. Пользователь нажимает «Запустить модель».
2. `LOADING` → движок поднимает ASR, перевод и XTTS (измерено: **20–23 с**).
3. `READY` — тост «модели загружены», кнопки переключаются.
4. «Остановить модель» → `STOPPING` → процесс выгружает модели и завершается,
   состояние `STOPPED`.

Автозагрузка при старте приложения **выключена** по умолчанию (настройка
«Автозагрузка моделей»).

### 4.2. Push-to-Talk

Зажать кнопку «Говорить (PTT)» → открывается микрофон → отпустить → сегмент
уходит в движок → перевод озвучивается в выбранное устройство (или в мост).

### 4.3. Непрерывный режим

Микрофон слушается постоянно, фразы режутся по паузам (0.55 с), тишина
отсекается по шумовому полу (20-й процентиль), «сильных» блоков должно быть
≥ 3. Глобальный хоткей `Alt+CapsLock` — push-to-talk (удержание).

### 4.4. Запись образца голоса

18 подсказок: пользователь записывает дубли, выбирает лучший, «Собрать
reference» собирает `reference.wav` (до 45 с), «Прослушать образец» играет его,
«Сравнить с образцом» считает схожесть.

### 4.5. Фразы

Банк 33 фраз (31 пресет + пользовательские), язык воспроизведения — из
настроек (es/en/ow/it). Свои фразы хранятся в `workspace/custom_phrases.json`.

### 4.6. Доставка в игру

Три маршрута (см. README): серверный ресурс, виртуальный кабель + мост,
локальный плеер. Новый UI покрывает второй (мост) и подготовку данных для
первого.

## 5. Языки

| Направление | Модель | Статус |
|---|---|---|
| RU → ES | `Helsinki-NLP/opus-mt-ru-es` (локально, CPU) | PASS |
| ES/EN/IT → RU (речь собеседника) | цепочка движка, `peer_lang` | UNVERIFIED (нужен звук игры) |
| RU → EN / IT / OW | цепочка движка + `lang` | UNVERIFIED |
| ASR | `mobiuslabsgmbh/faster-whisper-large-v3-turbo` (int8_float16) | PASS (22.5 с аудио распознано) |

## 6. Модели и ресурсы

- Модели не входят в EXE; грузятся движком из HF-кэша.
- Измерено при загрузке: перевод 3.9 с, ASR+перевод 7.1 с, XTTS + кэш голоса
  10.4 с, RSS ≈ 2.1 ГБ (`live_engine.log`).
- VRAM отображается в карточке на главной через `nvidia-smi` (в тестовой сессии
  8.7 / 16 ГБ до запуска движка).

## 7. Аудиосистема

- **Микрофон** — PortAudio через `sounddevice`, выбор устройства, запоминание
  (индекс + имя, с проверкой валидности).
- **Мост** `mic_bridge.py` — микрофон + фразы + синтез в одно устройство
  (виртуальный кабель), с ducking и громкостями.
- **Захват системного звука** — WASAPI loopback (`wasapi_loopback.py`).
- **VB-CABLE** — поиск, установка, проверка устройств (`cable.py`).
- **Индикатор уровня** — логарифмическая шкала (−55…0 дБ) из колбэка микрофона.

## 9. Требования к производительности (измерено ранее)

| Этап | Задержка |
|---|---|
| распознавание RU | 130–150 мс |
| перевод локально | 33–70 мс |

Загрузка моделей — 20–23 с (холодный старт).

## 10. Реализовано / запланировано

### Реализовано и подтверждено
- Qt-интерфейс, 5 разделов, дизайн-система (Card/Glow/AppButton/AppCombo/…).
- Управление жизненным циклом движка из UI, состояния, ошибки, перезапуск.
- PTT и непрерывный режим (логика), уровень микрофона, языки, живость.
- Сквозной пайплайн ASR → перевод → TTS (проверено на файле).
- История переводов, банк фраз, настройки, устройства, профили (чтение).
- Сборка EXE с Qt/QML и запуск.

### Запланировано (см. ROADMAP)
- Model Manager, единый выбор моделей и режимов Fast/Balanced/Quality.
- Universal Translation: автодетект, кэш, словари, профили пар.
- Streaming pipeline (частичные результаты, generation guards, backpressure).
- Audio Router: независимые маршруты, feedback gate, профили маршрутизации.
- Voice Studio 2.0 (темп/тон из бэкенда), OCR/Screen Translate, Plugin SDK.
- Диаризация, контекстные профили, экспорт истории.
- Брендинг и публичный релиз.

### Известные ограничения
- Отдельного состояния `WARMING UP` нет: прогрев входит в `LOADING`.
- Скорость речи и тон голоса в UI отсутствуют — бэкенд их не принимает.
- Длинная реплика может вернуться частичным переводом (наблюдалось на 22.5 с:
  распознано 11 фраз, переведены первые 4).
- Причина однократного падения движка в пользовательской сессии 2026-11-16
  не установлена; перезапуск после краха работает (проверено).

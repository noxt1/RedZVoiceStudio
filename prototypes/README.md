# Прототипы интерфейса Auraloom Voice Studio

## Auraloom_UI_Prototype.zip

Самостоятельный визуально-интерактивный прототип интерфейса на стандартном Python/Tkinter.

### Запуск прототипа
```bash
python main.py
```
(из папки `Auraloom_UI_Prototype/` после распаковки архива)

### Назначение
Архив является **самостоятельным визуальным прототипом**, а не заменой работающего приложения. Он не подключён к Engine, аудиоустройствам и пользовательскому workspace. Его единственное назначение — служить визуальным эталоном для дальнейшего развития существующего интерфейса приложения.

### Важные ограничения
- **Распаковка поверх `app/` запрещена.** Прототип не является частью исходного кода приложения и не должен сливаться с рабочим кодом GUI.
- Кнопки действий явно сообщают, что backend ещё не подключён.
- Никакие модели, пользовательские данные, аудиоустройства и файлы проекта не затрагиваются.
- Legacy UI и существующий Engine остаются неизменными.

### Связь с основным приложением
Элементы прототипа (тёмная основа, карточки, бронзовые акценты, разделение исходящего и входящего перевода, управление балансом звука, разделы Главная/Голоса/Настройки/История) используются как визуальный эталон. Функциональная интеграция выполняется через существующие сервисы проекта (`app/voice_studio.py`, `app/live_tab.py`, `app/mic_bridge.py` и др.), а не через код `main.py` из архива.
